recommendations

Switch research subagents from general-purpose → Explore. The 4 general-purpose calls averaged 3.4M tokens each vs Explore's 1.3M avg — same read-only task, 2.6× cheaper. Explore is purpose-built for codebase search; use it unless the task requires web fetch or writes.
Invoke /compact at ~70–80 API calls, not after 100+. The 813k cache break at Phase 4.2 came after 24 consecutive API calls from a context that was already large. A proactive /compact at the 70-call mark would have prevented the break and kept cache warm.
Don't re-run /init mid-session. /init ran 13× (2.9% of total tokens). In the 2026-04-29 marathon session it ran at least twice within the same day. The memory files it reads are stable — check them directly with Read instead of paying 1.4M tokens overhead per /init.
Paste external URLs after /compact, not before. The 661k cache break on 2026-04-27 was triggered by pasting a Google Drive URL into a large context. External URL context injections should come in a fresh post-compact window to avoid blowing the cache mid-session.
