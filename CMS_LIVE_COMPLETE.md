If you want to go live on the internet:

### Step 1: Add GitHub Secrets (2 min)
Go to: https://github.com/jvto-devteam/jvto-web/settings/secrets/actions

Add 3 secrets:
```
VERCEL_TOKEN = Get from https://vercel.com/account/tokens
VERCEL_ORG_ID = team_okkrKdwIyY1WFukLnT90kPlA
VERCEL_PROJECT_ID = prj_ZVekSWwRNYJzd7EuskXannhrisra
```

### Step 2: Add Vercel Environment Variables (2 min)
Go to: https://vercel.com/sams-projects-jvto/jvto/settings/environment-variables

Add:
```
DATABASE_URL
NEXTAUTH_SECRET
NEXTAUTH_URL
GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET
```

### Step 3: Test (1 min)
```bash
git push origin sam-workspace
# Watch it deploy at: https://github.com/jvto-devteam/jvto-web/actions
```
